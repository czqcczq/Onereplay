**两套独立判别口径**：track A / B / C 用 `allenai/wildguard`（三分类 harmful / refusal / other），1,650 个对齐 id；StrongReject track 用官方 grader `qylu4156/strongreject-15k-v1`（gemma-2b，0–1 有害分）。均做配对 McNemar 精确检验。

# 三、验证实验 2：math 域与 code 域

同一新任务（Commonsense170k）与同一套超参（LoRA r=8, `q_proj,v_proj`，3 epoch，lr 1e-4，accum 64，λ=3e-2），**唯一变量是正则项里的 C**。评测一律 greedy、`enable_thinking=False`、零 few-shot。

| 简称 | 正则 / C | 用于 |
|---|---|---|
| base | 未训练 | 两线 |
| vanilla | 无 | 两线 |
| cmix | C_mix = 0.5·C_if + 0.5·C_math | 数学线 |
| cif | 仅 C_if | 代码线 |
| cifcode | C_mix = 0.5·C_if + 0.5·C_code | 代码线 |

混合在协方差层面做凸组合（`mix_covariances.py`，`--weights 0.5,0.5 --normalize_weights 1`），**不是把两份语料混在一起重采**，也不是两个矩阵直接相加——权重归一化后 C_mix 的 trace 是两者的加权平均，因此 λ=3e-2 与纯 C_if 的 run 处于同一强度量级。

判分口径：MATH-500 认最后一个 `\boxed`（无兜底）；GSM8K 认 `####` 后数字（**有兜底**：无标记时取全文最后一个数字）；HumanEval / MBPP 沙箱执行，首个 `\ndef ` 处截断。代码绝对分数低于公开报告值，仅供组间对比。

# 附录：补充证据

## A. held-out 探针：Replay 的保护有多少来自记忆

每 64 次 optimizer update 评一次，3 epoch 共 124 个探针点，每个探针 1,000 行；loss 为对 base 自蒸馏 target 的交叉熵。`flan_heldout` 为池外（与训练池零 prompt 重叠），`flan_inpool` 为 replay 训练池本身。

训练结束时（epoch 3，第 7,872 次更新）：

| 方法 | held-out FLAN | in-pool FLAN | held/pool | CS val |
|---|---:|---:|---:|---:|
| Base | 0.1231 | 0.1302 | 0.95 | 12.82 |
| Vanilla | 0.4742 | 0.4892 | 0.97 | 0.0464 |
| Replay-50% | 0.1884 | 0.0304 | **6.19** | 0.0642 |
| **OneReplay** | 0.2669 | 0.2643 | **1.01** | 0.0494 |

相对 Vanilla 消除的遗忘量 `1 − (方法 − base)/(Vanilla − base)`：

| 方法 | 用 in-pool 衡量 | 用 held-out 衡量 |
|---|---:|---:|
| Replay-50% | 127.8% | 81.4% |
| **OneReplay** | 62.6% | 59.0% |

逐 epoch 轨迹（held-out）：

| 方法 | 探针 | ep1 末 | ep2 末 | ep3 末 |
|---|---|---:|---:|---:|
| Vanilla | held-out | 0.4795 | 0.5013 | 0.4742 |
| Replay-50% | held-out | 0.1131 | 0.1476 | 0.1884 |
| Replay-50% | in-pool | 0.0656 | 0.0421 | 0.0304 |
| **OneReplay** | held-out | 0.2953 | 0.2848 | **0.2669** |

探针为测量开销（每次约 15.7 s，124 次合计约 32 min），不计入 1.5 节的方法开销。
