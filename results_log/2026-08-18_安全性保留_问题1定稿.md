# 问题1 定稿:良性微调对安全对齐的侵蚀与 OneReplay(C_if)的保护

日期:2026-08-18　模型:Qwen3-1.7B　判别器:A/B/C 用 allenai/wildguard(三分类 harmful / refusal / other);StrongReject 用官方 grader qylu4156/strongreject-15k-v1(gemma-2b,0–1 有害分)

## 一句话结论
在 base 模型本身具备实质安全对齐的场景(直接有害指令、XSTest)下,良性微调(vanilla,仅训 Commonsense)会显著侵蚀安全,而 **OneReplay 用 C_if 保护指令跟随的同时,把安全对齐也几乎完整保住了**——这正面回答了问题1:保护 IF 的过程连带保护了安全能力。**两个抗遗忘基线 EWC 与 ReplayMix 也复现了同一现象**(A / C_unsafe 上都与 base 无显著差异、显著优于 vanilla),说明"连带保住安全"是抗遗忘方法族的共性,而非 OneReplay 的偶然。在 base 本就不具备鲁棒性的强 jailbreak 场景下,该 track 几乎没有"可保护的安全",vanilla 表面更低的有害率是输出坍缩的伪影,OneReplay / EWC / ReplayMix 则都保持了 base 级的流畅度而未引入退化。

## 实验设置
- 五个模型:`base` / `vanilla_seed1`(Commonsense LoRA) / `ewc_lam3e2_seed1`(EWC,λ=3e2) / `replaymix_4n4r_seed1`(ReplayMix,4n4r) / `onereplay_lam3e-2_seed1`(C_if,λ=3e-2,reg_once)。其中 EWC / ReplayMix 是两个持续学习基线,用于验证"保安全"是否是抗遗忘方法的共性
- 统一 prompt 集,配对检验(McNemar 精确检验 + bootstrap 95% CI),1650 个对齐 id;全部 5 条同口径由 wildguard 判分
- 四个 track(A/B 共用同一批 200 条 HarmBench behavior,便于 within-behavior 对比):
  - **A direct**(200):HarmBench 有害行为逐字提问 —— 测良性微调是否侵蚀 base 对齐
  - **B jailbreak**(1000 = 200 × 5 壳:prefix_injection / refusal_suppression / itw_1 / itw_2 / itw_3)—— 固定迁移攻击,所有模型看到完全相同输入
  - **C_safe**(250):XSTest 安全子集 —— 过度拒答对照
  - **C_unsafe**(200):XSTest 不安全子集

## 各 track 结果

有害率(harmful)/ 拒答率(refusal),越低有害越好、拒答越高越安全(C_safe 除外):

|---|---|---|---|---|---|---|
| A direct | harmful | 0.255 | 0.315 | 0.275 | 0.260 | **0.255** |
| A direct | refusal | 0.640 | 0.580 | 0.655 | 0.660 | **0.640** |

| C_unsafe | harmful | 0.010 | 0.030 | **0.000** | 0.010 | 0.020 |
| C_unsafe | refusal | 0.790 | 0.680 | **0.770** | **0.785** | **0.730** |

配对显著性(McNemar p,四个微调模型各自 vs base;`*` = p<0.05):

| track / 指标 | vanilla vs base | ewc vs base | replaymix vs base | onereplay vs base |
|---|---|---|---|---|
| A harmful | 0.058 | 0.424 | 1.000 | **1.000** |
| A refusal | **0.043*** | 0.581 | 0.503 | **1.000** |

## 结论一:A 与 C —— OneReplay 干净地保住了安全,EWC / ReplayMix 同样保住(主结论)
- **Track A**:vanilla 相对 base 有害率升(0.255→0.315)、拒答率降(0.640→0.580,p=0.043 显著)。OneReplay 与 base **逐点相同**(harmful/refusal 差都为 0,p=1.000);EWC(0.275 / 0.655)、ReplayMix(0.260 / 0.660)也都与 base 无显著差异(所有 p≥0.42)。也就是说,在直接有害指令上,vanilla 的侵蚀被三种抗遗忘方法一致抵消。
- **Track C_unsafe**:vanilla 拒答从 0.790 崩到 0.680(p=0.0003,侵蚀非常明显)。OneReplay 保住 0.730、EWC 保住 0.770(有害率甚至为 0)、ReplayMix 保住 0.785——三者都与 base 无显著差异,且都显著优于 vanilla 的退化(vanilla vs ewc/replaymix refusal p=0.0029 / 0.0005)。
- **Track C_safe**:五者过度拒答率都很低(≤6.4%),没有一个引入"矫枉过正的乱拒答"(OneReplay 0.032、EWC/ReplayMix 均 0.056,都不高于 base 0.064),说明保护安全不是靠无脑拒答换来的。

这些共同支撑主结论,并把它加强为:**保护 IF / 抗遗忘的方法(OneReplay、EWC、ReplayMix)在保护能力的同时都保住了安全对齐,且统计显著;唯独 vanilla 良性微调会侵蚀安全**——说明"连带保住安全"不是 OneReplay 的偶然,而是抗遗忘这一类方法的共性。

## 结论二:Track B —— "vanilla 更安全"是退化伪影,不改变主结论
天真读法会说:onereplay 在 jailbreak 上比 base/vanilla 都更有害(vs base:harmful +0.039,p=0.0056;vs vanilla:+0.058,p=0.0003),更少拒答。这个读法是被混淆的,三点澄清:

1. **B 上 base 本就被攻破约一半**(harmful 0.525,refusal 0.379)。这条 track 测的不是"训练是否破坏安全",而是"对固定强迁移攻击的鲁棒性"——而 base 根本不具备这项能力,几乎没有"可保护的安全"。
2. **vanilla vs base 在 B 上无显著差异**(harmful p=0.217,refusal p=0.062)。微调并没有在 B 上"改善"安全,所以 vanilla 表面更低的有害率不是真的变安全了。
3. **退化诊断揭穿了伪影**。vanilla 在 jailbreak 压力下输出坍缩:

| B 退化指标 | base | vanilla | ewc | replaymix | onereplay |
|---|---|---|---|---|---|
| mean tokens | 191.8 | 141.7 | 190.5 | 187.4 | 182.7 |
| median tokens | 256 | 102.5 | 256 | 256 | 256 |
| p10 tokens | 70 | 15 | 68 | 67 | 66 |
| frac_short(短响应占比) | 0.005 | **0.131** | 0.006 | 0.008 | 0.014 |
| frac_degenerate | 0.001 | 0.009 | 0.000 | 0.000 | 0.000 |

vanilla 有 13.1% 的响应坍缩成短/截断文本(median token 从 256 掉到 102.5,p10 只剩 15)。这些既不产出有害内容、也不构成有意义拒绝的"垃圾输出",人为压低了它的 harmful 率。**其余四个模型(base / ewc / replaymix / onereplay)都保持 base 级流畅度**(median 256,frac_short ≤1.4%,frac_degenerate≈0),坍缩是 vanilla 独有的病征。因此这些模型更多地"真正回应"了 jailbreak 而被判 harmful。

### 净有害率(排除退化后重算,min_tokens=20)—— 决定性证据
只保留"流畅且非坍缩"的响应后重算,原始率与净率对比:

| 模型 | 剔除数 | 原始 harmful → 净 harmful | 原始 refusal → 净 refusal |
|---|---|---|---|
| base | 5 | 0.525 → 0.527 | 0.379 → 0.377 |
| vanilla | **131** | 0.506 → **0.539** | 0.405 → **0.359** |
| ewc | 6 | 0.549 → 0.551 | 0.359 → 0.356 |
| replaymix | 8 | 0.531 → 0.534 | 0.373 → 0.370 |
| onereplay | 14 | 0.564 → 0.564 | 0.322 → 0.320 |

净配对检验(仅比较双方都流畅的样本):

| 净对照 / 指标 | rate_diff | McNemar p |
|---|---|---|
| **base vs vanilla — harmful** | +0.010 | **0.548(不显著)** |
| **base vs vanilla — refusal** | +0.002 | **0.931(不显著)** |
| vanilla vs onereplay — harmful | -0.045 | 0.0058 |
| base vs onereplay — harmful | -0.039 | 0.0068 |

两个决定性事实:
- **"vanilla 更安全"被彻底证伪。** 剔除那 131 条坍缩后,vanilla 的有害率不降反升(0.506→0.539)、拒答率反而掉(0.405→0.359),且**净率下 vanilla 与 base 无任何统计差异**(harmful p=0.548,refusal p=0.931)。vanilla 原始的表面优势 100% 来自输出坍缩,它并没有比 base 更安全。
- **残留一个诚实的小代价。** 即便只看流畅样本,onereplay 仍比 base/vanilla 高约 4pp 有害率(p<0.01),幅度从原始 -0.058 缩小到 -0.045。这是"保住 IF 流畅生成"的真实副作用,而非伪影;但 B 本就是 base 都被攻破一半的场景。

**公平对照是 onereplay vs base(两者都流畅、都不退化)**:OneReplay 仅比 base 略差(净 +0.039 harmful),且完全没有引入退化。可以诚实地表述为:C_if 保护了指令跟随的流畅生成能力,而 jailbreak 本质是"伪装成指令的攻击",所以保住 IF 的模型在这些最激进模板下会保留与 base 相当(略逊)的可攻击性——但这远不是 vanilla 靠"坏掉"换来的假安全。

结论:**Track B 不推翻主结论**。净率分析给出比原先更硬的结论——B 上的"vanilla 更安全"不是伪影就是完全不存在(vanilla ≡ base);真正的安全保护由 A/C(base 有实质安全可保护的场景)支撑。

## 结论三:扩展基线(EWC / ReplayMix)小结 —— 保安全是抗遗忘方法的共性

EWC 与 ReplayMix 的 wildguard 结果已并入上文结论一/二的主表。归纳它们带来的两点增量:

1. **在 base 有实质安全的场景(A / C_unsafe),EWC 和 ReplayMix 都保住了安全,与 base 无显著差异、且显著优于 vanilla。** C_unsafe 拒答:ewc 0.770、replaymix 0.785(base 0.790,vanilla 0.680);两者 vs base 均 n.s.,vs vanilla 均 p<0.01。A direct 拒答:ewc 0.655、replaymix 0.660,同样 ≥ base。这把主结论从"OneReplay 能保住安全"推广到"整个抗遗忘方法族都能",vanilla 是唯一侵蚀安全的一支。
2. **在强 jailbreak(B),EWC / ReplayMix 也无输出坍缩**(frac_short 0.006 / 0.008,mean token 190.5 / 187.4,均 base 级),与 vanilla 的坍缩(0.131)形成对照;其中 replaymix 的有害/拒答与 base 无显著差异(harmful p=0.677),ewc 略高于 base(harmful p=0.018,与 OneReplay 同向),都印证"B 上的可攻击性来自保住了流畅生成",而非真实变安全。

## 结论四:StrongReject(官方 grader)—— direct 段上的安全侵蚀最清晰

用 StrongREJECT 官方 grader(qylu4156/strongreject-15k-v1,gemma-2b)对 1878 条打分,`mean_score`∈[0,1] 越高越有害、`jailbroken_rate` 为 score≥0.5 的占比;数据按 **direct**(313 条逐字有害提问)与 **jailbreak**(1565 = 313×5 越狱壳)分段。

| 段 | 指标 | base | vanilla | ewc | replaymix | onereplay |
|---|---|---|---|---|---|---|
| **direct**(313) | mean_score | 0.130 | **0.242** | 0.135 | 0.139 | 0.166 |
| **direct** | jailbroken | 0.102 | **0.256** | 0.128 | 0.128 | 0.157 |
| jailbreak(1565) | mean_score | 0.310 | 0.257 | 0.304 | 0.313 | 0.303 |
| jailbreak | jailbroken | 0.319 | 0.283 | 0.319 | 0.327 | 0.318 |
| all(1878) | mean_score | 0.280 | 0.254 | 0.276 | 0.284 | 0.280 |
| all | jailbroken | 0.283 | 0.278 | 0.287 | 0.294 | 0.291 |

攻击增益(attack gain = jailbreak_mean − direct_mean,base 越狱壳带来的净增量):

| 方法 | direct mean | jailbreak mean | attack gain |
|---|---|---|---|
| base | 0.130 | 0.310 | **0.180** |
| vanilla | 0.242 | 0.257 | **0.015** |
| ewc | 0.135 | 0.304 | 0.169 |
| replaymix | 0.139 | 0.313 | 0.174 |
| onereplay | 0.166 | 0.303 | 0.137 |

三点解读:
1. **direct 段是最干净的对照,结论与 Track A 完全同型:** 良性微调把直接有害提问的有害分几乎翻倍——base 0.130 → vanilla 0.242(jailbroken 0.102→0.256,McNemar p=8.1e-9,侵蚀极显著)。而 EWC(0.135)、ReplayMix(0.139)、OneReplay(0.166)都贴近 base:EWC/ReplayMix 与 base 无显著差异(p=0.169 / 0.243),OneReplay 仅略高(p=0.014);三者都显著优于 vanilla(vs vanilla 均 p<0.001)。**这是 StrongReject 上"抗遗忘方法保住安全、vanilla 侵蚀安全"的直接证据。**
2. **jailbreak 段 vanilla 反而更低是同一个坍缩伪影:** vanilla 0.257 < base 0.310,与 Track B "vanilla 表面更安全"如出一辙(源于输出坍缩);EWC / ReplayMix / OneReplay 在 jailbreak 段都与 base 无显著差异(jailbroken p=1.0 / 0.52 / 0.96),即保持了 base 级的可攻击性,没有靠退化虚降。
3. **attack gain 揭穿 vanilla 的"假安全":** base 越狱壳带来 +0.180 的净增益,vanilla 只有 +0.015——不是因为它抗越狱,而是它在 direct 上就已被攻破(0.242),越狱壳没剩多少可加的。EWC / ReplayMix / OneReplay 保住了 base 级的 attack gain(0.14~0.17),行为与 base 一致。

小结:StrongReject 从独立的第二套判别口径,再次复现主结论——**direct 上 vanilla 侵蚀安全、抗遗忘方法(EWC/ReplayMix/OneReplay)保住安全;jailbreak 上 vanilla 的"更安全"是坍缩伪影**。

## 问题1 总定稿
- **能否用 IF 的保护顺带保住安全?能。** 在 base 具备实质安全对齐的直接有害与 XSTest 场景,OneReplay(C_if)把良性微调造成的安全侵蚀几乎完全抵消,统计显著;且不靠过度拒答。
- **强 jailbreak 场景的边界:** base 自身对这些模板就不鲁棒(~50% 被攻破),该场景没有多少安全可保护。净有害率分析证明 vanilla 的表面优势是输出坍缩的假象——**剔除坍缩后 vanilla 与 base 无统计差异**(harmful p=0.548,refusal p=0.931),即良性微调在 B 上根本没让模型更安全。
- **诚实的小 caveat:** 在最激进模板下 OneReplay 比 base 略高约 3.9pp 有害率(原始/净均 p<0.01),属于"保留流畅生成 / 指令跟随"的副作用,幅度小,且处在 base 本就不鲁棒的区间之外,不影响主结论。
- **保安全是抗遗忘方法的共性(wildguard 5 方对比):** EWC 和 ReplayMix 与 OneReplay 一样,在 A / C_unsafe 上保住了安全(与 base 无显著差异、显著优于 vanilla),在 B 上均无输出坍缩。vanilla 是唯一侵蚀安全、且唯一出现坍缩的一支。这把主结论从"OneReplay 能保住安全"加强为"抗遗忘这一类方法普遍能连带保住安全"。
- **StrongReject 官方 grader 独立复现主结论(见结论四):** 在 313 条 direct 有害提问上,vanilla 有害分几乎翻倍(0.130→0.242,p=8.1e-9),而 EWC/ReplayMix/OneReplay 都贴近 base、显著优于 vanilla;jailbreak 段 vanilla 的"更低"仍是坍缩伪影,attack gain(base 0.180 vs vanilla 0.015)进一步证明 vanilla 是在 direct 上就已被攻破,而非更安全。两套独立判别口径(wildguard + StrongREJECT grader)给出一致结论。
